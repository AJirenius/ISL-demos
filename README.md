# ISL demos

GOTV demo archive for the [International Senior League](https://internationalseniorleague.com) (CS2).

Each match is a release (`match-<id>`); each map's demo is a release asset
(`isl_<match>_map<N>.dem`), uploaded straight from the match server by
[MatchZy](https://github.com/shobhit-pathak/MatchZy)'s demo uploader at map end.
A GitHub Actions workflow in this repo re-pulls any demo the fire-once uploader
missed. Download links on the league site point at these release assets.

Demos are the league's own match recordings.
